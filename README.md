# vlad-prompts

A compact, portable library of system prompts, instruction prompts, and behavioral patterns for AI agents.

The main artifact is `core/VLAD.md`: a provider-agnostic instruction set designed to improve task interpretation, reasoning discipline, tool use, coding, debugging, verification, context efficiency, and communication.

This repository favors behavior that is:

> Understand precisely. Think compactly. Act minimally. Verify aggressively. Explain clearly.

Research sources, adapters, specialized modules, and evaluation scenarios live alongside the core prompt.
